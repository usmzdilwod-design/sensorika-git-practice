## Getting Started

This repository is used for practicing Git and GitHub.

### How to Clone the Repository

1. Install Git on your computer.
2. Open a terminal (CMD or Git Bash).
3. Run the following command:

git clone https://github.com/usmzdilwod-design/sensorika-git-practice.git

4. Open the downloaded project folder.
5. Read README.md and start practicing.
